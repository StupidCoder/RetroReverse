The tape loads in two stages: a short recording in the C64's standard KERNAL format bootstraps a custom fastloader — it announces itself on screen as NOVALOAD — which then streams the entire game at one bit per pulse while a loading screen plays music and an advert scroller.

Code hidden in a filename

A tape header block is 192 bytes: a type byte, a load address, a 16-character name and padding. The KERNAL loads the whole block into the cassette buffer at $033C — so the 171 “unused” bytes after the name FORT carry machine code, planted at $0351 before any program has officially loaded. That code is the fastloader's entire IRQ handler; the visible BASIC stub only has to bank the ROMs out and point the interrupt vector at it.

One bit per pulse

The KERNAL encoding spends two pulses per bit plus a parity bit per byte. The fastloader reads one bit per pulse: a CIA timer is force-reloaded on every cassette edge, and the handler reads its high byte — a short pulse is a 0, a long pulse a 1. Bytes assemble in a shift register pre-loaded with $7F, so the zero that falls out after eight shifts marks byte completion; during pilot search the register is never reset, which makes a run of zero-bits followed by a single one-bit read as the pilot byte and self-synchronises the decoder. The payload arrives as [page#] [256 bytes] [checksum] records that may come in any order — each page loads at page × 256 — and the game body streams in behind the loading screen, which decrements its BLOCKS TO LOAD counter once per page.

The entry address is hidden in the music

The loading-screen music is a command stream with three opcodes: play a note, loop the stream — and copy the next n stream bytes to any address. As loaded, the loader's epilogue ends in a plain RTS followed by decoy :RUN bytes, so a static reading (or a memory snapshot taken early) sees a harmless return to BASIC. The first commands of the tune, executed on its very first tick, patch RUN/STOP–RESTORE into a no-op and rewrite that RTS into JMP $8600 — the real game entry. The address exists nowhere in the code; it is data inside the song.

The error path

On a tape error the loading screen does not retry: it wipes all of RAM except its own page and jumps through the reset vector — anti-tamper as much as error handling.
